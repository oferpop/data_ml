# הגרלת שיר בהופעה

אפליקציית דף אחד (`index.html`) שמגרילה בזמן ההופעה מי מחברי קבוצת הוואטסאפ בוחר את השיר הבא.

## איך משתמשים
1. בוואטסאפ: נכנסים לקבוצה ← שם הקבוצה / ⋮ ← **ייצוא צ׳אט** ← „ללא מדיה”.
2. פותחים את `index.html` בדפדפן (טלפון או מחשב) ובוחרים את קובץ ה‑`.txt` ב„ייבוא צ׳אט”.
   כל מי שכתב בקבוצה, הצטרף בקישור או נוסף אליה נכנס לרשימה.
   הודעה שמתחילה ב‑`שיר:` (או `song:`) נשמרת כבקשת השיר של אותו חבר.
3. אפשר גם להדביק שמות ידנית, שם בכל שורה (`שם - שיר`).
4. לוחצים **הגרילו!** (או מקש רווח). הזוכה מופיע בגדול עם השיר שביקש, או שמקלידים את השיר שבחר.
5. הסט־ליסט נשמר בדפדפן ואפשר להעתיק אותו ולשלוח לקבוצה בסוף הערב.

אפשרויות: „כל אחד זוכה רק פעם אחת”, לחיצה על שם מוציאה אותו מההגרלה (למי שלא הגיע), מסך מלא, צליל, וביטול הזכייה האחרונה.
הכל רץ בדפדפן בלבד; הצ׳אט לא נשלח לשום שרת.
