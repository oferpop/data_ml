# הגרלת שיר בהופעה

להקת טריביוט לביטלס: הטופס והמשחק משתמשים ברשימת שירי הביטלס (`SONGS` בסקריפט) – הקהל בוחר שיר מרשימה, כך שהבקשות לשיר הסיום נספרות נכון.

מסך אחד לכל הערב, עם ארבעה חלקים (מקשים 1–4 מחליפים ביניהם, רווח/Enter/קליקר מפעילים):
1. **חידון ביטלס** – לפני ההופעה. הקהל עונה בטלפון על 10 שאלות בטופס ההרשמה (עם ניקוד), והמסך מציג 25 שאלות אחרות לסירוגין עם טבלת המובילים ו‑QR. על המסך: שאלה, 4 תשובות וטיימר, חשיפת התשובה, ו‑QR להרשמה כל 3 שאלות. השאלות נערכות בפאנל „שאלות החידון”.
2. **הגרלת שיר** – באמצע ההופעה: מי בוחר את השיר הבא.
3. **הגרלת חולצה** – מי זוכה בחולצה (כל אחד זוכה פעם אחת).
4. **שיר הסיום** – 5 השירים הכי מבוקשים מבין הבקשות, נחשפים מהמקום החמישי עד הראשון.

אפליקציית דף אחד (`index.html`) שמגרילה בזמן ההופעה מי מחברי קבוצת הוואטסאפ בוחר את השיר הבא.

## איך משתמשים
1. בוואטסאפ: נכנסים לקבוצה ← שם הקבוצה / ⋮ ← **ייצוא צ׳אט** ← „ללא מדיה”.
2. פותחים את `index.html` בדפדפן (טלפון או מחשב) ובוחרים את קובץ ה‑`.txt` ב„ייבוא צ׳אט”.
   כל מי שכתב בקבוצה, הצטרף בקישור או נוסף אליה נכנס לרשימה.
   הודעה שמתחילה ב‑`שיר:` (או `song:`) נשמרת כבקשת השיר של אותו חבר.
3. אפשר גם להדביק שמות ידנית, שם בכל שורה (`שם - שיר`).
4. לוחצים **הגרילו!** (או מקש רווח / Enter / קליקר מצגות). הזוכה מופיע בגדול עם השיר שביקש, או שמקלידים את השיר שבחר.
5. הסט־ליסט נשמר בדפדפן ואפשר להעתיק אותו ולשלוח לקבוצה בסוף הערב.

לינק הזמנה לקבוצה: מדביקים אותו בשדה „לינק ההזמנה” והמשחק מציג QR גדול על הבמה (כפתור „QR להצטרפות”), כדי שהקהל יסרוק ויצטרף.

מצב הקרנה (Resolume): מסך נקי על רקע שחור בלי כפתורים. רווח/קליקר מגריל, Q מציג/מסתיר את ה‑QR, Esc יוצא. בשכבה ב‑Resolume בוחרים Blend mode „Add” או „Screen” והשחור נעלם מעל הוויז׳ואלס.

## הרשמה דרך טופס גוגל (מומלץ לקהל זר)
הקהל סורק QR ← ממלא טופס (אישור השתתפות, אישור עדכונים, שם, שיר, טלפון ואזור) ← מקבל לינק לקבוצת הוואטסאפ, ונכנס להגרלה לבד.

1. ב‑script.google.com יוצרים פרויקט חדש, מדביקים את `create-form.gs`, ממלאים את ההגדרות למעלה ומריצים `createSongRaffleForm`.
2. ביומן ההרצה מופיעים: לינק לקהל, לינק לעריכת הטופס ולינק לגיליון.
3. בגיליון: קובץ ← שיתוף ← פרסום באינטרנט ← לשונית **במה** ← CSV ← פרסום. בלשונית הזו יש רק שם ושיר; הטלפונים נשארים בלשונית התגובות, שאינה מתפרסמת.
4. במשחק: מדביקים את לינק ה‑CSV ב„הרשמה בטופס”, ואת לינק הטופס בשדה ה‑QR.
   המשחק מושך נרשמים חדשים כל 15 שניות. דף ה‑claude.ai חוסם גישה לאתרים אחרים, ולכן משיכה אוטומטית עובדת רק כשפותחים את `index.html` ישירות בדפדפן. בדף ה‑claude.ai מורידים את לשונית „במה” כ‑CSV ומייבאים.

הנוסחים המשפטיים בטופס הם טיוטה (חוק התקשורת – „חוק הספאם”, וחובת היידוע בחוק הגנת הפרטיות). כדאי שעורך/ת דין יעבור/תעבור עליהם.

אפשרויות: „כל אחד זוכה רק פעם אחת”, לחיצה על שם מוציאה אותו מההגרלה (למי שלא הגיע), מסך מלא, צליל, וביטול הזכייה האחרונה.
מי שלא שמור באנשי הקשר מופיע בייצוא כמספר טלפון. על המסך מוצגות רק 4 הספרות האחרונות, והודעה שמתחילה ב‑`שם:` קובעת את השם שיוצג.

הכל רץ בדפדפן בלבד; הצ׳אט לא נשלח לשום שרת.
